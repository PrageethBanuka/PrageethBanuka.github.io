Pixi, and the RoboEyes that give it a face

An autonomous robot with on-device vision and a face that runs at 60 fps.

What
Pixi is an autonomous robot on a Raspberry Pi. TensorFlow Lite runs its vision on the device, with no cloud round trip. For its face I ported the RoboEyes animation library to Python.
How
A custom NumPy drawing engine renders each frame as an array and pushes it over SPI, skipping slow per-pixel drawing calls.
Try
Move your pointer. The eyes follow, the near eye grows when they look sideways, and they blink on their own.

Dual-Layer Steganography

A message hidden inside an image, invisible to the eye.

What
Hides data in the least significant bits of an image, then hardens it against automated steganalysis.
How
Layer one encrypts the payload with the TEA block cipher. Layer two scatters the bits to pixel positions derived from SHA-256, so the changes look like sensor noise.
Try
Type a message. It is written into the lowest bit of every pixel, which the eye cannot see. The lens shows that bit plane. Switch to Scattered: the same bits, placed in an order derived from a SHA-256 hash, now look like ordinary sensor noise.
